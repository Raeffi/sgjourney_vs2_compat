# About this mod
Have you ever tried to build a stargate on a VS2 ship ? Its a feeling comparable to trying to build an aether portal in vanilla. You dial an address, watch the gate open and try to enter ... only for nothing to happen.


This mod fixes the stargate and transport rings entity detection and coordinate calculations to work on a vs2 ship !

(No new blocks, mobs or items are added)

# Compatibility
Tested to work with these versions:
- Stargate Journey 0.6.44
- Valkyrien Skies 2.4.11
- The mod was not compatible with servers. This issue has been resolved for now.
